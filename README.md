# Kenya Market Prices

Analysis of food prices across Kenyan markets (`data/food-prices-kenya.csv`) in `analysis.ipynb`.

## Setup

Use the global Python 3.14 install (the project `.venv` is blocked by Windows Application Control):

```
python -m pip install -r requirements.txt
```

In VS Code, open `analysis.ipynb` and select the kernel **Python 3.14 (global)**
(`C:\Python314\python.exe`), not the `.venv` kernel.
